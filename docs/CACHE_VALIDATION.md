# Cache validation and revision checks

The supplied cache contains deterministic representations of the 1,035 ordered raw
SMILES. Its original `results/cache/CACHE_METADATA.json` is a legacy manifest: it
records the raw CSV hash and molecule count, but not the original generation
environment. The revision retains that manifest unchanged. The separate
`results/cache/CACHE_VALIDATION.json` records **current validation by fresh
recomputation**, not reconstructed historical provenance.

## Current verification

The validation run on 2 October 2026 (Asia/Shanghai) used Python 3.12.13, RDKit
2025.9.4, NumPy 2.5.3, pandas 3.0.1, SciPy 1.18.1 and scikit-learn 1.8.0. Exact
validation timestamps are stored in UTC in the machine-readable report. This run
does not revise environment claims for earlier runs.

Fresh computation from raw SMILES, without loading cached molecular arrays, gave:

- Exact equality for all four 1,035 by 1,035 kernels, all 1,035 by 12 descriptors,
  and all scaffold strings; maximum numerical difference was zero.
- Agreement of 9,315 held-out scores from all 45 primary SVMs, with maximum absolute
  difference 1.0703e-13 (acceptance tolerance 1e-8).
- A separate vectorized ECOTOX reconstruction matching binary labels, ternary
  levels and selected routes for all 441 compounds.
- Exact agreement of all 2,700 crossover AUROCs and 2,700 crossover gap rows with
  the 133,545 saved prediction rows. Independently reconstructed retained cohorts
  and labels reproduce both training-label models in all 225 `exclude` cells
  (450 fits), with maximum score difference zero.
- Fourteen deliberately invalid cache/metadata/split cases rejected, plus a
  successful new-cache generation and validation cycle in an isolated temporary
  directory. The cases include stale source hashes, reordered compounds,
  reordered symmetric kernels, missing files, nonfinite values, invalid shapes,
  changed representation/environment metadata, and duplicate split identities.
- Two historical 11-cutoff and six corrected-rule boundary cases passed.

Fresh molecular computation uses the documented representation implementation;
it is independent of cache contents, not a second independent fingerprint/kernel
implementation. Bootstrap interval endpoints are not independently regenerated by
the verifier; it checks requested/valid/degenerate draw accounting and metric/gap
algebra. The full analysis entry point regenerates the interval outputs.

Evidence is written to:

- `results/cache/CACHE_VALIDATION.json`: input/artifact hashes, versions,
  parameters, ordered identity hashes, and full-array comparisons.
- `results/reproducibility/revision_verification.json`: all checks and their scope.
- `results/reproducibility/primary_raw_smiles_refit.csv`: all 45 primary models.
- `results/reproducibility/ecotox_independent_reproduction.csv`: all 441 compounds.

## Routine loading and regeneration

Every existing-cache load checks the following before returning arrays:

1. Raw CSV SHA-256 and molecule count; complete ordered compound identities,
   metadata, derived tiers and endpoint labels in `processed_data.csv`.
2. Official split uniqueness, disjointness and complete cohort coverage; all seven
   raw/split input hashes in the applicable generation or validation record.
3. Ordered SMILES/compound identity digests; scaffold row indices and completeness.
4. Array shapes and finiteness; kernel symmetry, diagonal self-similarity and range.
5. Representation parameters/implementation digest, execution package versions,
   and SHA-256 of every cached artifact.

A partial, changed or unverifiable cache raises `CacheValidationError`. It is not
silently reused or replaced. A legacy cache without valid present-day evidence
can be checked without modifying its numerical files:

```shell
python verification/verify_revision.py --cache-only
```

Run the full revision verification after the analysis outputs exist:

```shell
python verification/verify_revision.py
```

New caches record schema-v2 generation metadata, including timestamp, raw/split
hashes, ordered identity hashes, parameters, versions, implementation digest,
array shapes and all cache artifact hashes. They do not need legacy attestation.
Explicit regeneration is available through `build_or_load_cache(force=True)` or
a clean full analysis run. To preserve released outputs, perform the latter in a
separate checkout/copy:

```shell
python code/run_all_analysis.py --clean
```

The entry point runs scripts 00 through 14, `verify_revision.py`, and the
exported-test-label check `check_crossover_nesting.py`, followed by the descriptive
cohort-structure check `describe_cohort_selection.py`.
`--clean` removes the checkout's `results` directory; the upstream ECOTOX and
external source exports under `output/external_data_audit` are separate frozen
inputs. Manuscript compilation and figure rendering are separate steps. Validation
does not download new records or modify the distributed benchmark labels.

## Historical 11-cutoff boundary

Script 11 deliberately preserves the upstream numerical rule: a group with
`min=11,max>11` is negative, whereas an all-exact-11 group is positive because the
first branch is evaluated first. This overlapping numerical boundary is historical
reproduction, not strict corrected unanimity. Script 12's corrected interval rule
distinguishes exact 11 (positive), `>11` (negative), and `>=11` (unresolved).
Exact 11 together with an exact value above 11 is unresolved under that rule.

The three retained historical groups at that numerical boundary contain `>11`,
not an exact 11 measurement, so they are not evidence of three wrong binary labels.
Script 11 now requires 441/441 matches for labels, levels and selected routes and
writes `results/tier_boundary/ecotox_replication_mismatches.csv` before failing if
the reproduction ceases to hold.
